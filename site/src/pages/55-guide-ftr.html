What AWS FTR certification actually checks

The Amazon Connect HubSpot connector holds AWS Qualified Software status, awarded after the AWS Foundational Technical Review (FTR). Here is what that review looks at, and why it matters more than a services badge.

What FTR is

The AWS Foundational Technical Review is a security and architecture assessment AWS runs on partner software before granting AWS Qualified Software status. It is not a badge a partner buys — it is a review of the actual product: how it handles data, what AWS services it touches, and whether its architecture follows AWS's own security guidance. Passing it is a listed prerequisite for AWS Qualified Software status on AWS Marketplace, which is where our AWS Marketplace listing states the connector holds this status.

Why this is different from a partner tier

AWS partner tiers (Select, Advanced, Premier) are a check on the company. FTR is a check on the product. When a customer's security team asks "has anyone independently reviewed this software," the answer for the HubSpot connector is that AWS has, as a condition of the AWS Qualified Software listing.

What we can say with confidence today

  • The connector deploys single-tenant, inside the customer's own AWS account, not shared infrastructure between customers — this follows directly from how the CloudFormation deployment works
  • HubSpot access is granted through a HubSpot Super Admin approving the connection, scoped to the objects the connector needs
