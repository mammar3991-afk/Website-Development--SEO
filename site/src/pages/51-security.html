Security and data handling

Where the connector runs, how it connects and who to contact.

QuestionAnswer
Where does the connector run?In the customer's own AWS account, in the region they choose, deployed with CloudFormation.
Where are recordings stored?In the customer's own S3 bucket, as configured in Amazon Connect.
How does the connector connect to HubSpot or Dynamics?A HubSpot Super Admin (or Dynamics 365 admin) approves the connection. Octavebytes does not need admin access to your CRM.
Single sign-onGoogle Workspace is supported.
AWS technical reviewThe connector holds AWS Qualified Software status through the AWS Foundational Technical Review (FTR), as shown on its AWS Marketplace listing. What FTR checks →
