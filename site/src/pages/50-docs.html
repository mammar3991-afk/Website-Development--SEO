Requirements and deployment

What to have ready, and how the connector gets into your AWS account. This page summarises the process; the full guides will live on a separate docs site. [[ASSET NEEDED: docs site, for example docs.octavebytes.com]]

Before you start

  • Amazon Connect instance alias and instance ID
  • AWS region of the instance
  • S3 bucket name where call recordings are stored
  • HubSpot Super Admin (or a Dynamics 365 administrator) to approve the connection. They do not need to give Octavebytes access.
  • Someone who can deploy a CloudFormation template in your AWS account
  • Your CRM object choice: contact-based, company-based or deal-based flow (HubSpot)

Two ways to deploy

OptionHow it works
CloudFormation (recommended)We give your AWS team a template. They run it in your account. We check the result with you.
Manual deployment (fallback)We give you the step-by-step guide and support you in a remote session.

The path from trial to production

  1. Trial on our hosted environment. Your agents test with real calls.
  2. Production in your AWS account. We deploy a build sized for your team.
  3. Single sign-on, transcripts and queue rules are configured as part of the setup where needed.
  4. Go-live check. An engineer stays with you until agents are taking calls.
