Prototype only

Colour options

Four options, each shown with the same components: header, hero, buttons, a plan card, a table, a form field, a dark section with the deployment diagram, and the footer. Every text and interface colour was measured against the accessibility thresholds: 4.5:1 for text and 3:1 for borders and focus rings.

To try one on the real pages, use the Colour option menu in the bar at the top of any page, or the button on each option below. Your choice is remembered in this browser only. This page is not included in a launch build.
